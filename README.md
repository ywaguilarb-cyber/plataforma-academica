# Plataforma Académica Básica

## 📌 Descripción del Proyecto
La **Plataforma Académica Básica** es un proyecto desarrollado como parte de la asignatura de **Ingeniería de Software III**. Su objetivo principal no es desplegar una aplicación compleja, sino servir como caso práctico para demostrar el dominio correcto del flujo de trabajo colaborativo utilizando **Git** y **GitHub**, aplicando estrategias de control de versiones mediante ramas (`feature branches`), commits descriptivos, Pull Requests y revisión de código en equipo.
